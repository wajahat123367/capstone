# User Stories — Farmers Marketplace App

1. As a new user, I want to sign up with a username, email, and password, so that I can create an account and access the app.
2. As a returning user, I want to log in with my email and password, so that I can access my personalized dashboard.
3. As a user, I want to see clear error messages when signup or login fails, so that I understand what went wrong and can correct it.
4. As a user, I want to see a home screen with a logo and a list of available products, so that I can browse what's on offer.
5. As a user, I want to tap on a product to view its details, so that I can learn more before deciding to buy or save it.
6. As a user, I want to mark products as favorites, so that I can quickly find items I'm interested in later.
7. As a user, I want my favorites and login session to be saved locally, so that I don't lose my data when I close the app.
8. As a user, I want the app to fetch live product data from an external API, so that I always see up-to-date listings.
9. As a user, I want to access a settings menu where I can manage my profile and notification preferences, so that I can control how the app behaves and be alerted about important updates.
